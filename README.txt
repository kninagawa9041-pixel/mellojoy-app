Mellojoy BOT 商品・在庫チェック版

今回の追加機能
- 公式ショップの公開商品データ（https://www.mellojoyjapan.com/products.json?limit=250）を取得
- 前回取得時と比較し、新商品・売り切れから在庫ありへの変化を表示
- 商品名で絞り込み
- 商品を既存の購入数量リストへ数量2個で追加（後から変更可能）
- アプリ起動時に取得し、画面の「最新情報を取得」から手動更新

重要な制限
- iPhoneでアプリを開いている間だけ取得します。閉じている間の常時監視・通知は行いません。
- 初回取得は比較用の基準データを保存します。新商品・再入荷の判定は2回目以降です。
- ブラウザのCORS制限、ショップ側の仕様変更、通信状況により商品データを取得できない場合があります。その場合は公式商品一覧を開いて手動確認してください。
- 商品データはShopify公開JSONの範囲で取得し、ログイン情報・Cookie・決済情報にはアクセスしません。
- 自動カート投入・注文確定・決済は行いません。

GitHub Pagesへの反映
1. 既存リポジトリの内容をこのフォルダ内の全ファイルで置き換えてください。
2. GitHub Pagesの公開先は従来どおり main / root です。
3. 公開後、iPhoneのホーム画面アプリを一度終了して再度開き、更新ボタンを押してください。
4. 以前のService Workerキャッシュを更新するため、初回は再読み込みを行ってください。

データ保存
商品名・URL・数量・在庫比較用スナップショットは端末内のlocalStorageに保存します。ブラウザデータを消去すると比較履歴も消えます。
