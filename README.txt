Mellojoy BOT（商品名・数量管理版）

■ この版でできること
・検索キーワード「スクイーズ」を初期入力した状態で公式ショップ検索を開く
・商品名を登録（商品URLは任意）
・商品ごとに購入予定数量を1〜99個で設定
・登録商品の購入予定数量の合計を表示
・商品URLが未登録の場合は、商品名で公式ショップ内検索を開く
・登録内容は利用中のブラウザ内（localStorage）に保存

■ iPhoneで使う方法
1. ZIPを展開し、フォルダ内のファイルをHTTPS対応のWebサーバーにアップロード
2. iPhoneのSafariで公開したURLを開く
3. 共有ボタンから「ホーム画面に追加」
※ローカルファイルを開くだけではPWA機能が動作しない場合があります。

■ 制限・安全性
・公式ショップの商品一覧や在庫を自動取得する機能はありません。
・商品情報は公式サイトで確認し、商品名をアプリに登録してください。
・パスワード、Cookie、カード番号、CVVは入力・保存しません。
・ログイン状態はSafariとホーム画面アプリで共有されるとは限らず、サイト側の仕様やセッション期限により再ログインが必要な場合があります。
・カート投入、注文確定、決済の自動操作は行いません。購入内容の確認と決済は公式サイトで手動で行ってください。
・CAPTCHA、待機列、購入制限、本人確認などを回避しません。
